# CR / KW / TD / LP の半自動化フロー（ADクロール ＋ Keywordmap ＋ Meta広告ライブラリ）

ニュース・業界はWeb検索で全自動化できるが、**CR・KW・TD・LP は専用ツールが必要**（＝有料ツールでしか取れない精度＝差別化ポイント）。
保有ツールを次の役割で使い分け、週1回エクスポート → 変換 → ダッシュボード読み込み、で運用する。

## ツールの役割分担

| 収集項目 | 主ツール | 取れるもの |
|---|---|---|
| **CR**（クリエイティブ） | **ADクロール** | 競合の新規バナー/動画/カルーセル（前日出稿を翌日収集）、訴求テキスト・キャッチコピー傾向、ブランド/企業指定の絞り込み |
| **LP** | **ADクロール（LPクロール）** | LP URLから誘導広告を一覧化／LPの訴求・販売経路分析。競合LPの変化検知 |
| **KW**（入札・順位） | **Keywordmap** | 検索順位レポート（登録KWの日次順位・下落KW検知・CSV/Excel出力）、リスティング広告調査（KW軸/競合軸でCPC・推定費用・掲載順位） |
| **TD**（広告文） | **Keywordmap** | リスティング広告調査で競合の広告見出し・説明文・クリエイティブ表示状況を抽出 |
| 補助（無料） | **Meta広告ライブラリ / Google広告透明性センター** | 現行クリエイティブの目視確認・裏取り |

→ **ADクロール＝CR/LP、Keywordmap＝KW/TD/順位/CPC** の二本柱。Metaライブラリは無料の裏取り。

## 週次オペレーション（月曜 30〜45分想定）

1. **Keywordmap**
   - 「検索順位レポート」を対象KW群でエクスポート（CSV）→ 上昇/下落KWを把握
   - 「リスティング広告調査」を競合4社軸でエクスポート（CSV）→ 広告見出し(TD)・CPC・推定費用・掲載順位・LP URL
2. **ADクロール**
   - 競合4社（ブランド/企業指定）の直近1週間の**新規クリエイティブ**をエクスポート
   - 主要LPを「LPクロール」にかけLP変化・誘導広告を確認
3. **Meta広告ライブラリ**（無料）で現行CRをざっと裏取り
4. **変換**：各エクスポートを本ツールのCSVスキーマへ変換（下記マッピング／変換プロンプト）
5. **ダッシュボード**で「CSV読み込み」→ 差分・AI要約を確認 →「レポート出力」で社内共有

## エクスポート → 本ツールCSV への変換マッピング

本ツールのスキーマ:
`週,カテゴリ,競合,媒体,重要度,日付,タイトル,先週,今週,AIメモ,入札上昇,入札下落,ネクストアクション,社外価値`

- **Keywordmap 検索順位レポート → KW行**
  - 順位が上がったKW → `入札上昇` に `KW名 (掲載順位 前→後)`
  - 順位が下がった/圏外KW → `入札下落` に `KW名 (前→後 / 圏外)`
  - `カテゴリ=KW`、`先週/今週`は空
- **Keywordmap リスティング広告調査 → TA行 / KW行**
  - 広告見出し・説明文の変化 → `カテゴリ=TD`、`先週=旧見出し`、`今週=新見出し`
  - CPC・推定費用の大きな変化 → `カテゴリ=KW`、`AIメモ`にCPC/費用の変化を記載
  - 抽出された **LP URL** → ADクロールLPクロールの入力に回す
- **ADクロール 新規クリエイティブ → CR行**
  - `カテゴリ=CR`、`媒体`=出稿媒体、`今週`=新しい訴求/キャッチ、`先週`=前の訴求（分かれば）
  - 訴求軸が変わった／量が急増 → `重要度=高`
- **ADクロール LPクロール → LP行**
  - `カテゴリ=LP`、`先週/今週`にLPのFV・CTA・フォーム等の変化

`ネクストアクション` `社外価値` は空でよい（ダッシュボードがカテゴリ別の「運用の型」を自動補完）。

## 変換プロンプト（エクスポートを貼るだけ）

```
以下は競合分析ツールのエクスポート（Keywordmap または ADクロール）です。
これを次のCSVスキーマに変換して。1つの変化=1行。事実のみ。判断の付加はしない。
スキーマ: 週,カテゴリ,競合,媒体,重要度,日付,タイトル,先週,今週,AIメモ,入札上昇,入札下落,ネクストアクション,社外価値
ルール:
- Keywordmap順位レポート → カテゴリKW、上昇は入札上昇、下落は入札下落に「KW (前→後)」
- Keywordmapリスティング調査の見出し変化 → カテゴリTD、先週=旧/今週=新
- ADクロール新規クリエイティブ → カテゴリCR、今週=新訴求
- ADクロールLPクロール → カテゴリLP、先週/今週にLP変化
- 重要度は訴求転換/急増=高、変更=中、軽微=低
- ネクストアクション・社外価値は空欄
- 値にASCIIカンマは使わない（全角・/で代替）。出力はBOM付きUTF-8のCSVのみ。
（この下にエクスポートを貼る）
```

## 将来のフルオート化（API連携があれば）
- Keywordmap / ADクロール に**APIやスケジュールエクスポート**があれば、GitHub Actions（`.github/workflows/weekly-collect.yml`）内で取得 → 変換 → CSV更新まで無人化できる。
- まずは「週1手動エクスポート → 変換プロンプト → 読み込み」の半自動で回し、運用が固まってからAPI化するのが安全。
