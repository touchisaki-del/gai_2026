# まるっと競合分析くん — 自動収集の仕組みと手順

ダッシュボード（`index.html` / Artifact）は**外部通信ができない**（Artifactはセキュリティ上禁止、ローカルでもCORSで他社サイトを直接読めない）。
そのため「ネットから引っ張る」処理は **コレクター（収集役）が別で実行 → CSV/JSONを出力 → ダッシュボードが読み込む** という分業にする。

```
[コレクター] 週1回実行
  Web検索 / 各社ニュース / 業界データ
        │  （競合の特定・業界動向・ニュースは自動取得しやすい）
        ▼
  competitive.csv  ←  実データに整形
        │
        ▼
[ダッシュボード]  CSV読み込み → 差分表示・AI要約・レポート出力
```

## 自動化の難易度（重要）

| 収集項目 | 自動取得 | 取得元 |
|---|---|---|
| 競合の特定・業界動向 | ✅ しやすい | Web検索・業界ランキング・各社IR |
| ニュース（プレスリリース・新サービス・料金） | ✅ しやすい | 各社ニュース欄・PR TIMES |
| TD（検索広告文） | △ 半自動 | 実検索の目視／リスティングツール |
| KW（出稿KW・入札・順位） | △ 半自動 | 自社広告アカウント／順位ツール |
| CR（広告クリエイティブ） | ⚠ 要ツール | Meta広告ライブラリ・Google広告透明性センター |
| LP（申込導線・FV・CTA） | ⚠ 半自動 | 競合LPの目視・スクショ比較 |

→ **ニュース・業界・競合はコレクターで全自動化できる。CR/KW/TD/LPは有料ツール連携 or 目視が必要**（＝ここの精度が有料ツールとの差別化ポイント）。

## コレクターの実行方法（どれか）

### A. このエージェント（Claude Code）を収集役にする ＝ 今回やった方法
下の「収集プロンプト」を貼って実行すると、Web検索して `competitive.csv` を生成する。
Claude Code on the web の **スケジュール実行（cron）** で週1回自動化も可能。

### B. Google Apps Script（社内GASウェブアプリ）＋ LLM API
- GASで各社ニュースURL / PR TIMES を取得 → LLMで要約・分類 → スプレッドシートに追記
- ダッシュボードはそのスプレッドシートをCSVエクスポートして読み込む
- （先に共有された `script.google.com/.../exec` を、この収集エンドポイントに拡張する構成が有力）

### C. 小さなサーバー（Node/Python）
- 検索API＋各社ニュースのスクレイピング → CSV/JSON出力 → 定期実行（cron）

## 収集プロンプト（コピペで再実行可能）

```
あなたは広告代理店の競合ウォッチ担当。以下の顧客について、直近1週間の競合の動きをWeb検索で集め、
competitive.csv（下記スキーマ、BOM付きUTF-8）を作成して。事実のみ・各行に出典を明記。推測は「(推測)」と明示。

顧客: 三菱地所ハウスネット（不動産売買・賃貸仲介／首都圏中心）
監視競合: 三井のリハウス / 東急リバブル / 住友不動産ステップ / 野村の仲介プラス
収集対象: 各社の①ニュース・プレスリリース ②新サービス・料金・キャンペーン ③業界動向
（CR/TD/KW/LPは公開ネットで取れる範囲のみ。取れなければ空欄でよい）

CSV列: 週,カテゴリ,競合,媒体,重要度,日付,タイトル,先週,今週,AIメモ,入札上昇,入札下落,ネクストアクション,社外価値
- カテゴリ: CR/TD/KW/LP/ニュース
- 重要度: 高/中/低
- ニュース行は「先週」を空、「今週」に発表内容
- AIメモに (出典: 媒体名) を必ず付ける
- ネクストアクション・社外価値は空でよい（ツール側で自動補完される）
```

## 運用イメージ
1. 週1回、上記プロンプトでコレクターを実行 → `competitive.csv` が更新される
2. ダッシュボードで「CSV読み込み」→ 差分・AI要約を確認
3. 「レポート出力」で社内共有用テキストを配布

※ 現行の `mec-h_auto_collected.csv` は初回収集ぶん（実在ニュース・出典付き）。CR/KW/TD/LPは含めていない（要ツール連携）。
